# ES6 Classes Project

This repository contains tasks and exercises focusing on modern JavaScript (ES6) classes, inheritance, getters, setters, static methods, and metaprogramming features like symbols.

## Tasks Covered
- **Task 0:** ClassRoom implementation
- **Task 1:** Make Classrooms
- **Task 2:** HolbertonCourse Validation
- **Task 3:** Currency Display
- **Task 4:** Pricing & Static Methods
- **Task 5:** Abstract Class Simulation (Building)
- **Task 6:** Class Inheritance (SkyHighBuilding)
- **Task 7:** Airport Symbol.toStringTag
- **Task 8:** Primitive Casting
- **Task 9:** Hoisting Fixes
- **Task 10:** Car Cloning via Species
